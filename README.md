# wnrs-mx

This repository auto-publishes the Spanish WNRS site at [wnrs.com.mx](https://wnrs.com.mx).

The site is built from [nickrec1986/wnrs](https://github.com/nickrec1986/wnrs) (`npm run build:mx`) on every push to `main`, on manual dispatch, and once a day. Content edits belong in that repository, not here.
